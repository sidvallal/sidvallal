## 📂 Featured Projects

### 🔍 [InsightAgent](https://github.com/sidvallal/insight-agent): AI Data Analyst (Text-to-SQL Agent)
An agentic AI analyst that turns plain-English questions into PostgreSQL queries and returns a table, a chart and a summary, through a React.js frontend.
- Multi-step **LangGraph** workflow: query router, schema retrieval, SQL generation and a self-correcting retry loop
- **RAG** over schemas and few-shot examples with ChromaDB, improving accuracy from 57% to 82% on a 50-question benchmark
- Safe execution with read-only transactions and query timeouts

`Python` `LangChain` `LangGraph` `Groq` `ChromaDB` `PostgreSQL` `React.js`

### 🎬 [AskTube](https://github.com/sidvallal/AskTube): Chat with Any YouTube Video
A RAG app that extracts a video's transcript, chunks and embeds it into ChromaDB, retrieves context with MMR and answers questions with Groq Llama 3.3 70B.

`Python` `LangChain` `Groq Llama 3.3` `ChromaDB` `Streamlit`
